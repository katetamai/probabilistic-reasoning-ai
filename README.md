# Probabilistic Reasoning and AI

## Overview
This project explores probabilistic reasoning techniques using Python, including particle filtering, Kalman filtering, and Bayesian networks.

## Project Components

### Particle Filtering
Implemented a particle filter to estimate a simulated car's position using noisy sensor measurements.

### Kalman Filtering
Implemented a Kalman filter to estimate the car's location and compare its performance with particle filtering.

### Bayesian Networks
Created a Bayesian network to examine relationships between racing conditions, such as speed, overtaking, crashes, and winning probability.

## Experiments
Tested different noise distributions, including Gaussian, Laplace, and Cauchy, and compared how they affected the accuracy of the filtering algorithms.
